# Smart Technology CRM

نظام CRM داخلي بيشتغل على سيرفر الشركة، لفريق المبيعات والمشتريات، ومتصمم إنه يكبر بعد كده ويبقى ERP كامل. عربي وإنجليزي من أول إصدار، ويب للمكاتب، و PWA للناس اللي بتشتغل برّه.

| | |
|---|---|
| **الاستضافة** | سيرفر فيزيائي في الشركة · VPN إجباري لأي دخول من برّه |
| **المستخدمين** | من عشرات لمئات، داخلي بس |
| **اللغات** | عربي + إنجليزي (RTL / LTR) من أول يوم |
| **الأجهزة** | ديسك توب للمكاتب · موبايل PWA للمبيعات الخارجية |
| **طريقة الشغل** | أونلاين بس — مفيش offline |
| **أيام الشغل** | الأحد → الخميس |
| **التقنيات** | Laravel · PostgreSQL · Redis · Meilisearch · REST `/api/v1` · WebSockets · SPA + PWA |

## ترتيب البناء

الموديولات بتتنفذ بالترتيب ده بالظبط — كل واحد معتمد على اللي قبله. الإعدادات والعملات والصلاحيات بييجوا **قبل** عروض الأسعار، علشان عروض الأسعار محتاجة التلاتة.

```
0  الأساسات            4  الكتالوج والموردين    8  الموافقات        12  الزيارات الخارجية
1  الهوية والصلاحيات   5  الصفقات               9  الـ PDF          13  التقارير
2  الإعدادات والعملات  6  عروض الموردين        10  رد العميل        14  لوحة المعلومات
3  العملاء             7  عروض العملاء         11  المشتريات        15  Meilisearch
```

الموديول مش بيخلص غير لما معايير القبول والاختبارات وفرض الصلاحيات وتغطية الـ audit وحالات RTL/LTR والـ migration القابل للتراجع كلهم يعدّوا.

## قواعد سهل تتكسر

- **الفلوس `Decimal`.** الـ floating point ممنوع نهائيًا في أي حتة قريبة من سعر.
- **كل الحسابات في الـ backend.** الواجهة ممكن تعرض، بس عمرها ما تبقى مصدر الحقيقة.
- **التقريب على الإجمالي النهائي بس**، بوحدة العملة المضبوطة.
- **الصلاحيات بتتفرض على مستوى الـ API والصف.** إخفاء زرار مش صلاحية.
- **مفيش حذف نهائي.** تعطيل أو أرشفة بس.
- **PDF العميل عمره ما يعرض اسم مورد ولا سعر مورد ولا تكلفة ولا هامش ربح.**
- **مفيش نصوص مكتوبة في الكود** ولا enums ولا صلاحيات ولا قيم ثيم.

## النماذج

### P-01 — الـ PDF العربي (عدّى ✅)

أنهى `R-02`، أعلى مخاطرة تقنية في المشروع: تشكيل الحروف العربية في الـ PDF.

```bash
cd prototypes/p01-arabic-pdf
npm install
node render.js
```

بيطلّع عرض السعر بالعربي والإنجليزي من قالب واحد، بستايل Smart Technology. كل الخطوط مضمّنة، والبناء بيفشل لو أي لغة زادت عن صفحة واحدة.

## الشغل مع الوكلاء

المستودع فيه أتمتة جاهزة في `.claude/`:

| | |
|---|---|
| `/module-kickoff` | بيبدأ موديول بالسياق الصح وبيطلّع الهيكل كامل |
| `/doc-sync` | بيتأكد إن الملفات التوأم (عربي↔إنجليزي، CLAUDE↔AGENTS) متطابقة |
| `permission-matrix-auditor` | بيراجع الـ endpoints على مصفوفة الصلاحيات |
| `pricing-invariant-reviewer` | بيراجع كود الفلوس على سلسلة الحسابات في القسم 5 |

فيه `PreToolUse` hook بيمنع التعديل على المستندات التلاتة المرجعية. ده مقصود: تغيير قرار موثّق لازم يبقى **قرار**، مش تعديل عابر. لو محتاج تغير واحد فعلاً، اقفل الـ hook من `/hooks`.
