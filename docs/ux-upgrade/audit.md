# F-42 · 2.3 — UI/UX audit, one prioritized list

This is one list that merges the 2.1 code audit (163 findings) and the 2.2 browser audit (56 notes).

The raw inputs are untracked in `docs/ux-upgrade/raw/`:
- code: `notes-shell.md` `SH-*`, `notes-deals-customers.md` `DC-*`, `notes-quotations.md` `Q-*`
- browser: `notes-browser.md` `B-*`

Every raw id appears below exactly once, either in a row's **Raw ids** cell or in [§3](#3-negative-results-and-coverage-notes). Screens are `S1`…`S13` from [`screen-map.md`](screen-map.md).

**Severity** follows the 2.1 brief:
- **blocker**: a user cannot complete a task.
- **major**: misleads or slows daily work, or fails WCAG AA.
- **minor**: rough but works.
- **polish**: a matter of taste.

There are **0 blockers**.

**Order.** Within each severity, rows run usability and accessibility first and consistency or polish last (the owner's ranking, 2026-10-12).

**How a merged row is graded.** It takes the highest severity among its raw ids. The browser notes carried no severity, so each browser-only row is graded here on the brief's scale, with the reason in the row.

**Overlap.**
- **F-41**: no change until F-41 · 1.6–1.8 close.
- **F-37 / F-33**: the owner's open Arabic manual test lists walk this screen.
- **non-UI**: the full fix needs an API, permission, route or data change. The UI-only part is still named, and the rest is not F-42's to build.
