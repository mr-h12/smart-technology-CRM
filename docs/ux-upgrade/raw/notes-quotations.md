## Patterns
- Error text never tied to its field: `grep -rn "aria-describedby" pages/quotations pages/supplier-quotations components/pdf` → 1 hit (PdfPanel only); danger-colored error spans in slice: `grep -c "text-\[var(--color-danger)\]"` builder 9, modal 10.
- No focus management after submit/add/remove: `grep -n "\.focus()" pages/quotations/*.vue pages/supplier-quotations/SupplierQuotationFormModal.vue` → only QuotationDetailView 275, 283 (response form).
- `:focus` instead of `:focus-visible`: `grep -c "focus:outline-2"` builder 14, modal 17, list 8, detail 3, PO 1 vs `focus-visible:` only in QuotationPdfPanel (3). Detail action buttons, builder row-actions and list filters have none (browser default).
- No hover state on secondary buttons: `grep -n ":hover" pages/quotations/*.vue pages/supplier-quotations/SupplierQuotationFormModal.vue` → 1 (list row only).
- Identical "Remove"/"إزالة" names for every row remove button: builder 4 call sites of removeItem/removeSupplier, modal 1 per line.
- `.form-field` / `.row-action` / `.form-alert` redeclared per file (6 files) and `.form-alert` differs: danger border in Builder/Modal, neutral border in Detail/PO/PdfPanel — same class name, two looks (detail comment 769-770 already records it as a debt row).
- Clean: no raw hex/rgb or Tailwind palette colours, no physical left/right classes (`grep -nE "\b(ml|mr|pl|pr|left|right)-[0-9]|text-(left|right)"` → 0).
