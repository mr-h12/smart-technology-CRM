## Patterns
- `focus:` instead of `focus-visible:` for rings: 219 vs 24 — `grep -rn "focus:outline-2" --include='*.vue' resources/js | wc -l` / same for `focus-visible:outline-2`. No global :focus-visible fallback (SH-49).
- No focus trap / inert anywhere: `grep -rn "'Tab'\|inert" resources/js` → 0 code hits; `role="alertdialog"` 10 times, only 2 with aria-modal on the next lines (`grep -rn 'role="alertdialog"' -A2 --include='*.vue' resources/js | grep -c aria-modal`).
- Light-veil scrim in Midnight Obsidian (SH-07) repeated in 12 modals/drawers: `grep -rn "color-mix(in srgb, var(--color-text)" resources/js`.
- Undefined `--shadow-3` referenced 11 times: `grep -rn "shadow-3" resources/js | wc -l`.
- Page h1 duplicating the context-bar h1: 23 page files have `<h1` (`grep -rl "<h1" resources/js/pages | wc -l`).
- Copied scoped CSS: `.form-field` defined in 24 files, `.row-action {` in 21, `.state-plate {` in 3 (`grep -rln "^\.form-field" resources/js`, `grep -rn "^\.row-action {"`). Comments already register this as debt — noted, not a finding.
- Off-scale radius `rounded-2xl` 21 hits (`grep -rn rounded-2xl --include='*.vue' resources/js | wc -l`); raw Tailwind text sizes 10 hits (`grep -rnoE "\btext-(xs|sm|base|lg|xl|2xl)\b" --include='*.vue'`); raw Tailwind palette colours 0 hits; raw shadow utility 1 hit (SH-14).
- No document.title per route: `grep -rn document.title resources/js` = 0.
- Busy buttons communicate only by opacity (SH-10, SH-29, SH-35) — LoginView.vue:177 is the one that follows §6.1.
