تشغيل الـ CRM على جهاز واحد وفتحه من باقي أجهزة المكتب

جهاز Windows واحد يشغّل النظام، والباقون يفتحونه من المتصفح على نفس الشبكة.

0 / 0
⚠️ اعرف هذا قبل أن تبدأ هذه الخطوات لم تُجرَّب على Windows بعد. نجحت على الـ Mac، والـ images تُبنى بنجاح لمعالجات Intel/AMD، لكن التشغيل نفسه على Windows لم يحدث. خذ وقتاً كافياً (حوالي ساعتين). وإذا ظهر خطأ، صوّره وأرسله كما هو.
🏠 للتجربة في البيت الـ Lenovo يكون الجهاز المضيف (نفّذ عليه الخطوات 1–8). والـ Mac يكون «جهاز الموظف». لا تفحص الاتصال بـ ping، لأن Windows يمنعه افتراضياً. افحص من Terminal على الـ Mac بهذا الأمر:
Mac — Terminal
nc -z -G 3 <LENOVO-IP> 443 && echo OPEN
إذا طبع OPEN فالاتصال سليم. ولا تحتاج فلاشة ولا موافقة أحد.

قبل أن تذهب

التجهيز

  • نزّل Docker Desktop for Windows من docker.com على فلاشة.
  • خذ موافقة العميل على تثبيت برامج في جهازه.
  • تأكد أن الأجهزة الثلاثة على نفس الشبكة، وليست شبكة ضيوف.

على الجهاز المضيف

1. هل الجهاز يدعم Docker؟

افتح cmd واكتب:

cmd
systeminfo
في آخر النتيجة: Virtualization Enabled In Firmware: Yes أو A hypervisor has been detected

أو من Task Manager، ثم Performance، ثم CPU (وليس Memory)، ستجد في الأسفل Virtualization: Enabled.

إذا كانت No: أعد التشغيل، واضغط F2 عند ظهور شعار الشركة (أو Del / F10 حسب الجهاز). ابحث عن Intel Virtualization Technology أو SVM، واجعلها Enabled، ثم F10 للحفظ.

2. تثبيت Ubuntu

اضغط بزر الماوس الأيمن على PowerShell واختر Run as administrator:

PowerShell — مسؤول
wsl --install -d Ubuntu

عندما ينتهي، أعد تشغيل الجهاز. بعد التشغيل تفتح نافذة Ubuntu وحدها وتطلب منك:

  • username: اكتب crm
  • password: اختر كلمة سر واكتبها في الورقة. لن تظهر أثناء الكتابة، وهذا طبيعي.
يظهر سطر ينتهي بـ $. بعدها أغلق النافذة.

Ubuntu هنا برنامج داخل Windows ولا يغيّر نظام التشغيل. يُحذف بسهولة بعد التجربة.

3. تثبيت Docker Desktop

  1. شغّل ملف التثبيت، وتأكد أن Use WSL 2 مُعلَّم، ثم OK.
  2. إذا طلب إعادة تشغيل، أعد التشغيل.
  3. افتح Docker Desktop، ثم Accept، ثم Skip / Continue without signing in.
  4. من ⚙️ Settings ثم General: تأكد أن Start Docker Desktop when you sign in مُعلَّم.
أسفل يسار النافذة يظهر Engine running باللون الأخضر.

4. تنزيل المشروع من هنا وحتى الخطوة 6: في Ubuntu

افتح Ubuntu من قائمة Start.

Ubuntu
docker version
يظهر قسم اسمه Server:

إذا لم يظهر: من Docker Desktop افتح Settings، ثم Resources، ثم WSL integration، وفعّل Ubuntu، ثم Apply & restart. بعدها أغلق Ubuntu وافتحه مرة أخرى.

Ubuntu

Ubuntu

5. الإعداد (لصق فقط)

أ. الصق الكتلة كلها مرة واحدة واضغط Enter. عندما تسألك عن كلمة سر، اكتب حروفاً وأرقاماً فقط، 8 أو أكثر، بدون رموز (مثل Trial2026abc)، واكتبها في الورقة. هذه هي كلمة سر الدخول للموقع.

Ubuntu
cp .env.example .env && cp crm/.env.example crm/.env
PG=$(head -c 24 /dev/urandom | od -An -tx1 | tr -d " \n"); RD=$(head -c 24 /dev/urandom | od -An -tx1 | tr -d " \n"); MS=$(head -c 24 /dev/urandom | od -An -tx1 | tr -d " \n")
read -s -p "Test users password (letters+numbers): " SP; echo
sed -i "s/^POSTGRES_PASSWORD=.*/POSTGRES_PASSWORD=$PG/; s/^REDIS_PASSWORD=.*/REDIS_PASSWORD=$RD/; s/^MEILI_MASTER_KEY=.*/MEILI_MASTER_KEY=$MS/; s/^HTTP_PORT=.*/HTTP_PORT=80/; s/^HTTPS_PORT=.*/HTTPS_PORT=443/" .env
sed -i "s/^DB_PASSWORD=.*/DB_PASSWORD=$PG/; s/^REDIS_PASSWORD=.*/REDIS_PASSWORD=$RD/; s/^APP_DEBUG=.*/APP_DEBUG=false/; s/^SEED_TEST_USER_PASSWORD=.*/SEED_TEST_USER_PASSWORD=$SP/" crm/.env

ب. الصق هذه الكتلة كاملة. هي التي تسمح لباقي الأجهزة بفتح الموقع:

Ubuntu
cat > docker-compose.override.yml <<'EOF'
services:
  nginx:
    ports: !override
      - "0.0.0.0:${HTTP_PORT:-8080}:80"
      - "0.0.0.0:${HTTPS_PORT:-8443}:443"
EOF

7. العنوان والنوم

cmd
ipconfig

خذ IPv4 Address من قسم Wireless LAN adapter Wi-Fi (أو Ethernet إذا كان بكابل). لا تأخذه من vEthernet (WSL).

مثال: 192.168.1.35 ⇐ فيكون الرابط https://192.168.1.35. اكتبه في الورقة.

من Settings، ثم System، ثم Power: عند التوصيل بالكهرباء اجعل Sleep = Never. وإذا كان لابتوب، اجعل إغلاق الغطاء = Do nothing.

8. جرّب على الجهاز نفسه

افتح Chrome على https://localhost. سيظهر Your connection is not private، فاضغط Advanced ثم Proceed.

تظهر شاشة الدخول

على جهاز كل شخص من الثلاثة

فتح الموقع وتسجيل الدخول

  1. افتح Chrome على https://<IP> (العنوان الذي في الورقة).
  2. سيظهر تحذير، فاضغط Advanced ثم Proceed. هذا طبيعي، ويحدث مرة واحدة فقط لكل جهاز.
  3. اضغط ⭐ لحفظ الرابط في المفضلة.
  4. سجّل الدخول بحساب من الجدول. كلمة السر هي التي كتبتها في الخطوة 5، وهي نفسها لكل الحسابات.
  5. أنشئ عرض سعر واحفظه، ثم ولّد PDF ⇐ يجب أن يُفتح بالعربي.
الإيميلالدور
indoor.sales@example.testمبيعات مكتبية: ينشئ عروض الأسعار
manager@example.testمدير: يعتمد العروض
procurement@example.testمشتريات
ceo@example.testالمدير العام
outdoor.sales@example.testمبيعات ميدانية
تنبيهان اكتب الرابط دائماً بـ https://، فشاشة عرض السعر لا تعمل على http.
إذا أخطأ أحد في كلمة السر 5 مرات يُقفل حسابه، فيستعمل حساباً آخر من الجدول.

قبل أن تغادر

اختبار إعادة التشغيل

أعد تشغيل الجهاز المضيف، وسجّل الدخول، وانتظر دقيقتين حتى يظهر الحوت 🐳 بجوار الساعة. ثم افتح الموقع من جهاز آخر.

الموقع يعمل بدون كتابة أي أمر

قل لصاحب الجهاز ثلاث قواعد

  • لا تغلق Docker Desktop (الحوت 🐳).
  • لا تطفئ الجهاز وزملاؤك يعملون.
  • بعد أي إعادة تشغيل، سجّل الدخول لـ Windows، فالموقع لا يعمل قبل ذلك.

إذا لم يعمل

المشكلةالحل
الموقع يفتح على الجهاز المضيف ولا يفتح على باقي الأجهزةنفّذ أمرَي جدار الحماية في الأسفل
ظهرت port is already allocated في الخطوة 6نفّذ أمر تغيير المنفذ في الأسفل. يصبح الرابط https://<IP>:8443
كان يعمل ثم توقف عند الجميعالجهاز نام، أو Docker مغلق، أو الـ IP تغيّر. نفّذ ipconfig وقارن بالورقة
أي خطأ آخرصوّره وأرسله كما هو

جدار الحماية (PowerShell كمسؤول؛ إذا كان الجهاز موصولاً بكابل اكتب Ethernet بدل Wi-Fi):

PowerShell — مسؤول
Set-NetConnectionProfile -InterfaceAlias "Wi-Fi" -NetworkCategory Private
PowerShell — مسؤول
New-NetFirewallRule -DisplayName "CRM trial" -Direction Inbound -Protocol TCP -LocalPort 80,443,8080,8443 -Action Allow -Profile Private

تغيير المنفذ:

Ubuntu — داخل ~/crm-system
sed -i "s/^HTTP_PORT=.*/HTTP_PORT=8080/; s/^HTTPS_PORT=.*/HTTPS_PORT=8443/" .env && docker compose up -d
🚫 ممنوعdocker compose down -v: هذا الأمر يمسح كل البيانات.
