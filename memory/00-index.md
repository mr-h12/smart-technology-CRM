# مخ المشروع

نقطة البداية. الملاحظات هنا **مش مصدر** — المصدر هو `docs/`.

## شكل الملاحظة

كل سؤال في `memory/questions/` بيبدأ بـ frontmatter بالشكل ده:

```yaml
---
type: question
id: OD-03
status: open | resolved
owner: مين المسؤول
blocks: إيه اللي متوقف عليه
opened: YYYY-MM-DD
---
```

وبعدين: السؤال · ليه مهم · بيمنع إيه · الإجابة لما تيجي.

## ⚠️ القاعدة اللي لو اتكسرت المنظومة بتقع

| النوع | مكانه | مين بيشوفه |
|---|---|---|
| قرار **معتمد** | `docs/CRM_Documentation_EN.md` كـ `D-xx` | الوكلاء + الفريق |
| التفكير اللي وصل للقرار | هنا في `memory/` | إنت |
| سؤال مفتوح | `memory/questions/` **و** `README.md` | الاتنين |

**قرار عاش هنا بس = قرار مش موجود.** Claude Code بيقرا `docs/` و `CLAUDE.md`، مش ملاحظاتك.
ودي بالظبط المشكلة اللي حصلت مع الملفات العربية واتحلت بـ `D-58`.
