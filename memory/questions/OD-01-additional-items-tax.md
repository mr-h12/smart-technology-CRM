# OD-01 — البنود الإضافية عليها ضريبة؟

## السؤال

البنود الإضافية (توصيل، تركيب) بتدخل في وعاء الضريبة ولا لأ؟

## ليه مهم

المعادلة في `§5.2` مكتوبة كده:

```
tax_base = net_amount + additional_total   ⚠️ OD-01
```

يعني **الافتراض الحالي "أيوه"** — وده افتراض مؤقت موثّق، مش قرار.

## بيمنع إيه

`Module 7` (عروض أسعار العملاء) — سطر واحد بالظبط.

## طريق يفك الحصار من غير الإجابة

نخليها **إعداد في الداتابيز** (`tax_includes_additional_items`) بدل ما تكون في الكود.
المواصفات بتطلب كده أصلاً (`AP-08` الإعدادات بدل الكود).

**بشرط:** يظهر في لوحة الـ Super Admin بعلامة **"غير مؤكد"** لحد ما المحاسب يعتمده.
من غير كده هيتنسي، وهيروح عرض سعر للعميل بضريبة غلط.

## القرار الحالي

**سايبينها زي ما هي** — البنود الإضافية **داخلة** في وعاء الضريبة:

```
tax_base = subtotal + additional_total
```

⚠️ **لسه افتراض مش تأكيد.** لازم يتعرض في لوحة الـ Super Admin بعلامة **"غير مؤكد"**
لحد ما المحاسب يعتمده.
