# OD-03 — مواصفات السيرفر

## السؤال

مواصفات السيرفر إيه؟ و**هل اتشترى أصلاً؟**

## ليه مهم

بيمنع `P-02`، و `P-02` بيمنع كل الموديولات رسميًا (البند السابع في تعريف الإنجاز:
"اترفع على السيرفر واختبار الدخان عدّى").

## سؤال فرعي مهم: Linux ولا Windows؟

| | مع Docker | من غير Docker |
|---|---|---|
| **Linux** | ✅ المواصفات مكتوبة عليه | ✅ |
| **Windows** | ✅ تغيير شبه صفر | ❌ **Redis مالوش نسخة رسمية على Windows** |

`§14.2` حاطط على Redis الكاش والجلسات والطوابير وتحديد المعدل والأقفال.
البديل التجاري (Memurai) مدفوع.

## لو السيرفر لسه ما اتشتراش

**يبقى ده اختيار مش اكتشاف** — اختار **Ubuntu Server LTS**:
مجاني، والمواصفات كلها مكتوبة عليه، ومفيش مشكلة Redis.

## الحد الأدنى للرام

السيرفر هيشغّل PostgreSQL + Redis + Meilisearch + PHP + Nginx **مع بعض تحت حمل حقيقي**.
8 جيجا = الحد الأدنى، مش المريح.
