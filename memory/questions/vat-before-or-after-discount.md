# الضريبة قبل الخصم ولا بعده؟

## السؤال

الوعاء الضريبي بيتحسب **قبل** الخصم ولا **بعده**؟

## ليه ده طلع

من أمر الشراء الحقيقي بتاع الشركة (رقم 226):

```
الإجمالي قبل الضريبة    7,368.42
ضريبة 14%               1,031.58   ← على المبلغ الكامل قبل الخصم
اشعار خصم 1%              −73.68
الإجمالي بعد الضرايب    8,326.32
```

بس `§5.2` بيقول العكس:

```
discount_amount = subtotal × discount_percent / 100
net_amount      = subtotal − discount_amount
tax_base        = net_amount + additional_total   ← الضريبة على المبلغ بعد الخصم
```

## الفرق

على نفس أمر الشراء ده:

| الطريقة | الإجمالي |
|---|---|
| طريقة الشركة (ضريبة قبل الخصم) | 8,326.32 |
| طريقة المواصفات (خصم الأول) | 8,316.00 |
| **الفرق** | **10.32 جنيه** |

## ليه مش تفصيلة

**الوعاء الضريبي مختلف.** ده موضوع ضرايب، مش تفضيل حسابي.
وواحد من الاتنين غلط.

## الإجابة ✅

**اتقرر: الضريبة تتحسب قبل الخصم** — زي أمر الشراء بالظبط.

```
tax_base           = subtotal + additional_total
tax_amount         = tax_base × 14%
discount_amount    = subtotal × 1%
total_before_round = tax_base + tax_amount − discount_amount
```

اتحقق منها على أمر الشراء 226: `8,326.32` ✅ مطابق للقرش.

**اتسجّل كـ: `D-60`**

### ⚠️ سؤال فاضل للمحاسب

السطر مكتوب **«إشعار خصم»** — وده في المحاسبة **credit note**، مستند منفصل بيعدّل فاتورة صدرت.
لو ده اللي هو، يبقى الخصم مش مكانه عرض السعر أصلاً، والضريبة كانت بتتحسب صح من الأول.
اسأله: *«ده خصم على الفاتورة ولا إشعار خصم منفصل؟»*
