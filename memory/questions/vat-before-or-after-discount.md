# الضريبة قبل الخصم ولا بعده؟

## السؤال

الوعاء الضريبي بيتحسب **قبل** الخصم ولا **بعده**؟

## ليه ده طلع

من أمر الشراء الحقيقي بتاع الشركة (رقم 226):

```
الإجمالي قبل الضريبة    7,368.42
ضريبة 14%               1,031.58   ← على المبلغ الكامل قبل الخصم
اشعار خصم 1%              −73.68
الإجمالي بعد الضرايب    8,326.32
```

بس `§5.2` بيقول العكس:

```
discount_amount = subtotal × discount_percent / 100
net_amount      = subtotal − discount_amount
tax_base        = net_amount + additional_total   ← الضريبة على المبلغ بعد الخصم
```

## الفرق

على نفس أمر الشراء ده:

| الطريقة | الإجمالي |
|---|---|
| طريقة الشركة (ضريبة قبل الخصم) | 8,326.32 |
| طريقة المواصفات (خصم الأول) | 8,316.00 |
| **الفرق** | **10.32 جنيه** |

## ليه مش تفصيلة

**الوعاء الضريبي مختلف.** ده موضوع ضرايب، مش تفضيل حسابي.
وواحد من الاتنين غلط.

## الإجابة الأولى ❌ (اتلغت)

اتقرر في 2026-08-12 إن **الضريبة قبل الخصم**، وده اتسجّل `D-60` واتحقق منه على أمر الشراء 226.
الوعاء وقتها كان `subtotal + additional_total` — وده كمان اتلغى لما `OD-01` اتقفل.

## الإجابة النهائية ✅ (2026-08-19)

**الضريبة تتحسب بعد الخصم.** صاحب المشروع أكّدها.

```
discount_amount    = subtotal × discount_percent / 100
tax_base           = subtotal − discount_amount     ← بعد الخصم، والتوصيل بره الوعاء
tax_amount         = tax_base × tax_percent / 100
net_amount         = subtotal + additional_total − discount_amount
total_before_round = net_amount + tax_amount
```

على نفس أرقام أمر الشراء 226:
`7,368.42` ناقص خصم `73.6842` = وعاء `7,294.7358` · ضريبة 14% = `1,021.2630` ·
الإجمالي `8,315.9988` → **8,316** لو التقريب شغّال.

⚠️ أمر الشراء نفسه مكتوب فيه `8,326.32` لأنه بيحسب الضريبة على المبلغ قبل الخصم.
**فرق الـ 10.32 ده اتقبل، وأمر الشراء 226 بقى مش مرجع لترتيب الضريبة.**

**اتسجّل كـ: `D-64`** — وبيلغي `D-60` صراحة.

### ⚠️ سؤال لسه فاضل للمحاسب

السطر مكتوب **«إشعار خصم»** — وده في المحاسبة **credit note**، مستند منفصل بيعدّل فاتورة صدرت.
لو ده اللي هو، يبقى الخصم مش مكانه عرض السعر أصلاً.
اسأله: *«ده خصم على الفاتورة ولا إشعار خصم منفصل؟»*
الإجابة دي ممكن تغيّر **إيه هو الخصم**، مش **فين بيتحسب**.
